# Code and data availability

This repository provides the source code described in [README.md](README.md), with input definitions in [INPUT_DATA_DICTIONARY.md](INPUT_DATA_DICTIONARY.md). The code is licensed under MIT.

No participant-level data are distributed. UK Biobank data access requires approval through [UK Biobank](https://www.ukbiobank.ac.uk/enable-your-research/apply-for-access/). All participant-level inputs and derived outputs must remain in an authorised research environment.

Synthetic tests exercise the software independently of study data. The scope and upstream preparation requirements in the README define which analyses can be reproduced with appropriate inputs.
